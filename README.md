# Voi — Nos pays et nos villes

Page web autonome (un seul fichier `index.html`) qui présente les pays et les villes où Voi propose ses vélos et trottinettes électriques en libre-service :

- carte interactive de l'Europe (jsVectorMap, chargée depuis jsDelivr) avec un point par ville ;
- une page par pays (`#france`, `#allemagne`, `#pays-bas`…) avec zoom automatique sur le pays et la liste des villes ;
- une page détaillée par territoire français (`#paris`, `#marseille`, `#nantes`…) : zone desservie, tarifs, FAQ ;
- recherche par pays ou par commune.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer **GitHub Pages** (Settings → Pages → branche `main`, dossier `/`) pour obtenir une URL publique.

## À valider avant mise en ligne

Les données (villes, volumes estimés, tarifs) proviennent de sources publiques et d'estimations internes : à vérifier avec les équipes Voi, en particulier Bruxelles, Bristol, Liverpool, Bergen, l'Espagne et le Portugal.
